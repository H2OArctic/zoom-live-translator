# Documentation

Zoom Live Translator provides local English ↔ Russian speech translation on macOS. The app interface currently uses Russian labels; instructions below describe the controls in English.

- [Setup](setup.md): prerequisites, signed builds, permissions, and preparing local models.
- [Usage](usage.md): listening, translating your microphone, Zoom routing, recovery, and speaker names.
- [Recognition and translation](recognition.md): engine behavior, vocabulary, phrase grouping, and quality warnings.
- [Privacy and recording](privacy-and-recording.md): stored conversation data, exports, retention, and networking.
- [Development](development.md): source layout, build configuration, checks, and diagnostic tools.
- [Validation history](validation.md): historical measurements and the limits of existing verification.

For the project overview and first launch, return to the [main README](../README.md).
